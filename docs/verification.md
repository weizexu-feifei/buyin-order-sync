# 验证范围

当前候选版已通过47项离线/模拟测试。安装wheel后在独立虚拟环境（复用本机已有openpyxl依赖）验证了虚构文件预览、受监护worker在缺少登录资料时停止，以及隐藏界面构建且不自动启动任务。Windows计划任务脚本只做语法检查，未执行注册。未访问真实机构、未创建飞书业务记录。

候选版使用人工构造的订单和模拟飞书接口，验证金额/补贴/整单退款、付款日归属、ID精度和身份变化、重复订单、文件行数、旧快照保护、差异写入、重复键、响应丢失、待确认批次和写后读回。

本机检查CLI帮助和接口参数契约，适配官方@larksuite/cli 1.0.94；测试不使用真实凭据，不创建或读取真实飞书Base，不登录或提交百应导出。UI隔离构建和内部worker缺资料停止检查也不能替代真实平台验收。

发布者需在自己的独立测试机构/空表完成接入验收：先导入一个完整日，再重复同源确认跳过，再导入退款更新确认回原付款日，最后运行独立check，记录差异及限制。测试报告只能分享脱敏统计；真实报表、日志、配置和路径保持私有。生产稳定性应按实际多日结果说明，不能依据单次成功承诺长期无人值守。

持续集成只跑虚构离线测试，不接收平台账号、飞书Token或其他业务秘密。
